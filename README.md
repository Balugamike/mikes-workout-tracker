# Mike's Workout

A small, phone-first pecs and abs workout tracker. The app saves workout progress in the browser's local storage on the device; it has no account or server-side storage.

## Publish with GitHub Pages

1. Create a new GitHub repository for this app.
2. Upload the contents of this folder to the repository's top level. Keep `index.html`, `manifest.webmanifest`, `service-worker.js`, `icon.svg`, and `.nojekyll` together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)`. Save.
5. When the deployment finishes, open the published URL in Safari on the iPhone. Use **Share → Add to Home Screen**.

On GitHub Free, the repository must be public to use Pages. The published site is public too. Workout entries stay in the browser and are not uploaded to GitHub.
